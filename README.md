# 📸 Digital Image Processing (DIP) Lab Repository

Welcome to the Digital Image Processing (DIP) laboratory course repository. This repository contains interactive web applications, image processing algorithms, and practical implementations built using Python, OpenCV, and Flask.

---

## 🛠️ Tech Stack & Tools

* **Programming Language:** Python 3.x
* **Core Libraries:** OpenCV (`cv2`), NumPy
* **Web Framework:** Flask
* **Frontend:** HTML5, CSS3 (Glassmorphism UI, Canvas Animations)
